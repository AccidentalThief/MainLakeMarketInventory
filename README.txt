=====================================================
  DeliTrack - Deli Inventory Manager
  Installation Instructions
=====================================================

INSTALLING THE APP
------------------
1. Open this folder
2. Double-click  INSTALL.bat
3. If Windows asks "Do you want to allow this app to make changes?"
   click YES
4. Wait for it to finish (takes 1-3 minutes the first time)
5. A "DeliTrack" icon will appear on your Desktop
6. Double-click it to open the app!

That's it. You only need to run INSTALL.bat once.


USING THE APP
-------------
- Inventory    - See everything you have in stock
- Orders       - Log when new stock arrives
- Stock Count  - End of day: type in what you actually have
- Admin        - Fix mistakes (password required, default: admin123)

Your data is saved automatically to a file called
deli_inventory.db in the DeliTrack folder.


UPDATING THE APP
----------------
If you receive a new version, just double-click INSTALL.bat
again — it will update automatically.


BACKUP YOUR DATA
----------------
To back up your inventory data, copy the file:
  C:\Users\[YourName]\DeliTrack\deli_inventory.db
to a USB drive or email it to yourself.
